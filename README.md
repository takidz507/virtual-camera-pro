# Virtual Camera Pro — مشروع الكاميرا الوهمية الأصلي للأندرويد (بدون روت)

تطبيق أندرويد أصلي (`com.takidz.vcam`) مكتوب بلغة **Java + Material Design 3 + Camera2 API** يتيح لك اختيار أي فيديو من هاتفك وبثه بدلاً من الكاميرا الحقيقية مع إمكانية **التبديل اللحظي السريع** بين الفيديو المختار والكاميرا الحقيقية، والتحكم في التكرار (`Loop`)، والانعكاس الأفقي (`Mirror`)، ودقة البث (`480p` / `720p` / `1080p`).

---

## قيود نظام Android الرسمية وكيف يتجاوزها هذا المشروع (بدون روت)

في نظام أندرويد القياسي، قائمة الكاميرات الفيزيائية التي ترجعها `CameraManager.getCameraIdList()` محمية داخل نواة النظام عبر عملية `cameraserver` وطبقة `Camera HAL`، كما أن واجهة `VirtualDeviceManager` في Android 14 محصورة بصلاحية `CREATE_VIRTUAL_DEVICE` (`signature|privileged`) الخاصة بتطبيقات النظام فقط.

لذلك، يدمج هذا المشروع **4 حلول تقنية عملية تعمل بدون روت** داخل تطبيق واحد لتغطية جميع الاستخدامات:

1. **متصفح الكاميرا الوهمية المدمج (Built-in WebRTC Virtual Camera Browser) — يعمل 100% بدون روت:**
   - يحقن طبقة JavaScript تعترض `navigator.mediaDevices.getUserMedia` قبل تحميل أي موقع ويب.
   - أي موقع ويب يطلب الكاميرا (مثل مواقع الدردشة المرئية، Zoom Web، Google Meet Web، ومواقع اختبار الكاميرا مثل `webcamtests.com`) سيرى الفيديو المختار كأنه بث كاميرا حقيقية بدقة 480p أو 720p أو 1080p، مع زر أعلى المتصفح للتبديل الفوري إلى الكاميرا الحقيقية دون إعادة تحميل الصفحة.

2. **اعتراض طلبات الكاميرا النظامية (`ACTION_IMAGE_CAPTURE` & `ACTION_VIDEO_CAPTURE`) — يعمل 100% بدون روت:**
   - مسجل في `AndroidManifest.xml` ككاميرا رسمية للنظام.
   - عندما يطلب أي تطبيق خارجي (تيليجرام، واتساب، المتصفحات، أو نماذج رفع الكاميرا) التقاط فيديو أو صورة عبر نافذة الكاميرا النظامية، يظهر **Virtual Camera Pro**، ويعرض لك الفيديو المختار مع زر إرسال مباشر للتطبيق الطالب.

3. **أداة التحكم العائمة (`FloatingControlService`) — تعمل 100% بدون روت:**
   - نافذة عائمة صغيرة تبقى فوق أي تطبيق آخر (واتساب، تيليجرام، زوم) وتتيح لك التبديل بضغطة واحدة بين **🎬 الفيديو الوهمي** و **📷 الكاميرا الحقيقية**.

4. **محرك الحقن المباشر في `Camera2` و `Camera1` المتوافق مع LSPatch (بدون روت):**
   - يحتوي المشروع على الكلاس `VirtualCameraXposedHook.java` ومزود المحتوى `VirtualVideoProvider.java`.
   - لتشغيل الكاميرا الوهمية داخل المكالمات المباشرة لتطبيقات الطرف الثالث المغلقة (مثل مكالمة فيديو واتساب أو تيليجرام أو زوم الأصلية) **بدون روت**، يمكنك استخدام أداة **LSPatch** (أداة مفتوحة المصدر تدمج الموديول داخل ملف APK للتطبيق المستهدف بدون روت)، حيث يقوم `VirtualCameraXposedHook` تلقائياً باعتراض `CameraDevice.createCaptureSession` و `Camera.setPreviewTexture` وحقن الفيديو المختار من تطبيقنا مباشرة!
